# CAIC Porting Plan: Cubic → Arch Linux

This document maps every Ubuntu/Debian-specific piece of the Cubic codebase to
its Arch Linux equivalent. It is the work plan for converting this repository
into a working **CAIC (Custom Arch ISO Creator)**.

## Reference: ISO layouts

### Ubuntu/Debian live ISO (what Cubic was built for)

```
<iso-root>/
├── .disk/                    # release metadata (info, release_notes_url)
├── README.diskdefines
├── casper/                   # live filesystem
│   ├── vmlinuz               # kernel
│   ├── initrd                # initramfs (initramfs-tools)
│   ├── filesystem.squashfs   # live root
│   ├── filesystem.manifest   # installed package list
│   ├── filesystem.size
├── isolinux/                 # BIOS boot
├── boot/grub/, EFI/          # UEFI boot
└── md5sum.txt
```

### Arch Linux live ISO (archiso / releng profile, current layout)

```
<iso-root>/
├── arch/
│   ├── boot/
│   │   ├── syslinux/         # BIOS boot (memdisk + syslinux)
│   │   └── x86_64/
│   │       ├── vmlinuz-linux           # kernel
│   │       └── initramfs-linux.img     # initramfs (mkinitcpio + archiso hook)
│   └── x86_64/
│       ├── airootfs.sfs      # THE live root squashfs
│       └── airootfs.img      # optional FAT image (kernel+initramfs, USB assist)
├── boot/                     # UEFI: boot/grub/, loader/, arch/…
├── EFI/boot/BOOTx64.EFI
├── isolinux/                 # isolinux.cfg + ldlinux.c32 (BIOS)
├── loader/                   # systemd-boot entries (newer archiso)
└── pkglist.x86_64.txt        # installed packages manifest (optional)
```

Key differences for CAIC:

| Concept          | Ubuntu (Cubic) | Arch (CAIC) |
|------------------|----------------|-------------|
| Root squashfs    | `casper/filesystem.squashfs` | `arch/x86_64/airootfs.sfs` |
| Kernel           | `casper/vmlinuz` in-tree, uppercase `.disk` | `arch/boot/x86_64/vmlinuz-linux`, part of pacman pkg `linux` |
| Initramfs        | `casper/initrd`, regenerated by `update-initramfs` (initramfs-tools) | `arch/boot/x86_64/initramfs-linux.img`, regenerated by `mkinitcpio` |
| Release metadata | `.disk/info`, `README.diskdefines`, `.disk/release_notes_url` | none on ISO; read `/etc/os-release` inside the rootfs |
| Package manager  | `apt` / `dpkg` (python3-apt) | `pacman` |
| Chroot terminal  | `systemd-nspawn` via `machinectl` (name `caic`) | same approach works, or `arch-chroot` for one-shot ops |
| Package manifest | `filesystem.manifest` (dpkg-query) | optional `pkglist.x86_64.txt` (pacman -Q) |
| Boot params      | kernel cmdline + preseed (isolinux/grub) | kernel cmdline in isolinux/grub/systemd-boot (no preseed) |
| Installer config | debconf preseed | not applicable → replace with pacman.conf/mirrorlist |
| Snap packaging   | snap page | not applicable → replace page |
| ISO generated w/ | xorriso report + template | xorriso (same), Arch layout paths |

## Module-by-module plan

### 1. Model / layout detection — `utilities/model.py`, `utilities/structures.py`
**Status: not ported.**

Add an Arch layout section mirroring the existing "Casper" + "Squashfs" +
"Live/Installer" sections:

- `arch_boot_directory(x86_64)`, `kernel_file_name` (vmlinuz-linux),
  `initramfs_file_name` (initramfs-linux.img), `airootfs_directory`
  (`arch/x86_64`), `airootfs_file_name` (`airootfs.sfs`), optional
  `airootfs_img_file_name` (`airootfs.img`).
- Add "detect" logic in the Extract page that first probes for the Arch
  layout, then falls back to the Ubuntu/Debian layout (both remain supported
  for now).

### 2. ISO info — `utilities/iso_utilities.py`
**Status: not ported.**

- `get_iso_release_name()` reads `.disk/info` and `README.diskdefines` (both
  absent on Arch ISOs). For Arch: read `/etc/os-release` (NAME/PRETTY_NAME)
  after extracting, or parse the ISO volume id (e.g. `ARCH_202609`) via
  `isoinfo -d`.
- `get_iso_release_notes_url()` → drop or point at archiso docs.
- `get_iso_report()` + xorriso template machinery (interval path / partition
  images): **reusable as-is** — this is boot-record plumbing, not distro logic.

### 3. Package queries — `utilities/constructor.py`
**Status: not ported (primary work).**

Replace every `apt`/`dpkg`/`dpkg-query` call with `pacman`:

- `get_package_version()` / `get_package_version_01..04()` (lines ~456–684):
  use `pacman -Q <pkg>` (installed) or `pacman -Si <pkg>` (repo).
- `get_installed_packages_list()` / `_01()`: use `pacman -Qq`/`pacman -Q`.
  Check `--root <dir>` support for foreign-root queries (`pacman --sysroot`).
- `get_kernel_version()`: use `uname -r` fallback (`pacman -Q linux`).
- Remove `python3-apt` dependency entirely. Implement the equivalent via
  `pyalpm` (AUR) or, preferably, subprocess to `pacman` to avoid AUR deps.

### 4. Console terminal / chroot — `utilities/console.py`, `commands/start-console`, `stop-console`
**Status: plumbing renamed (machine name `caic`), logic unchanged.**

The embedded terminal uses `systemd-nspawn` + embedded pty (VTE). This works
on Arch unchanged (`systemd` ships `systemd-nspawn`). Verify `start-console`
argv still matches; consider adding an `arch-chroot` toggle for non-interactive
operations.

### 5. Extract page — `pages/extract_page.py`, `commands/extract-root`, `commands/merge-directory`
**Status: not ported.**

`unsquashfs` works on `airootfs.sfs` identically. `merge-directory` stays.
Points to change:
- default squashfs path regex: `casper/filesystem*.squashfs` → `arch/x86_64/airootfs.sfs`.
- (optional) handle multiple-appended-image (`airootfs.img`) — not needed for
  the live root.

### 6. Compression page — `pages/compression_page.py`, `commands/compress-root`
**Status: reusable as-is.**

`mksquashfs -comp zstd/gzip/xz/lzo/lz4` is identical. archiso ships zstd
typically — keep zstd default.

### 7. Prepare page — `pages/prepare_page.py`
**Status: partially reused.**

Prepares `custom-root` + binds `/proc /sys /dev`. For Arch also bind
`/run` (needed by pacman), and copy `/etc/resolv.conf`. Add the Arch
`arch-chroot` hint string in the UI.

### 8. Terminal/package operations inside the rootfs
**Status: not ported.**

New UI text + helper to install packages inside the chroot via
`pacman -S --root …` or `arch-chroot`. For pacman to work in an extracted
live root the chroot MUST also include:
- a working mirrorlist (`/etc/pacman.d/mirrorlist`)
- `${rootfs}/var/lib/pacman` and `${rootfs}/etc/pacman.d/gnupg` (pacman keyring,
  init with `pacman-key --init` + `--populate archlinux`)
- `/run` and `resolv.conf`
- `Architecture = x86_64` in `${rootfs}/etc/pacman.conf` if it was built
  otherwise.

### 9. Packages page — `pages/packages_page.py`, `pages/snaps_page.py`
**Status: not ported.**

- Packages page: list packages from `pacman -Sl` (available) and `pacman -Q`
  (installed inside rootfs); size via `pacman -Si`.
- Snaps page: Ubuntu-only. **Replace** with a page for pacman repo/mirror
  management (or remove). Recommended: "Repositories & Keyring" page.

### 10. Options page — `pages/kernel_tab.py`, `pages/preseed_tab.py`, `pages/boot_tab.py`, `pages/options_page.py`
**Status: not ported.**

- Kernel tab: instead of installing Ubuntu kernel .debs, select which Arch
  kernel (linux / linux-lts / linux-zen / linux-hardened) and regenerate the
  initramfs with `mkinitcpio` using the rootfs' `/usr/lib/modules`, then write
  `arch/boot/x86_64/vmlinuz-*` + `initramfs-*.img`. `lsinitcpio` replaces
  `lsinitramfs` for inspecting the initramfs.
- Preseed tab: **remove** — debconf preseed has no Arch equivalent.
- Boot tab: edit kernel cmdline in `isolinux/syslinux.cfg`, grub entries and
  `loader/entries/*.conf`; add `archiso` options (`copytoram`, `verify`,
  `archisobasedir`, etc. live here).

### 11. Generate / Finish pages — `pages/generate_page.py`, `pages/finish_page.py`
**Status: not ported.**

Copy the extracted + re-squashed root into a working ISO tree laid out like
the Arch layout above, then invoke `xorriso` with the same template trick
(report as_mkisofs), substituting Arch paths. Keep El Torito + UEFI + MBR
handling. Volume label should be archiso-style (`ARCH_YYYYMM`).

### 12. Emulator page — `utilities/emulator.py`
**Status: reusable.**

QEMU invocation is distro-agnostic. Dependency changes only: `qemu-system-x86`
→ `qemu-full` (or `qemu-system-x86`), plus `edk2-ovmf` for UEFI boot testing.

### 13. Helpers / commands
**Status: mostly reusable; `replace-text`, `copy-path`, `delete-path`,
`move-path`, `mount-iso`, `unmount-iso`, `test-command`, `stop-process`,
`file-size`, `directory-usage`, `current-directory` are distro-agnostic.**
No change.

### 14. Files/editor — `utilities/files_tree.py`, `files_tab.py`, `file_utilities.py`
**Status: reusable.**

### 15. Busywork / buildchain
- `.disk` handling, `filesystem.manifest`/`filesystem.size`: drop or map to
  `pkglist.x86_64.txt`.
- `initramfs-tools` (`lsinitramfs`) → `mkinitcpio` (`lsinitcpio`).
- `genisoimage` (mkisofs) → `xorriso` (libisoburn) only.
- `isolinux` → `syslinux` (`isolinux.bin`, `memdisk`).

## Execution order (recommended)

1. Layout detection + ISO info (items 1–2). Verify on a real Arch ISO.
2. Extract + compress cycle on `airootfs.sfs` (items 5–6).
3. Console/chroot + pacman keyring bootstrap (items 4, 7, 8).
4. Packages page + repo/keyring page (item 9).
5. Options page (kernel via mkinitcpio, boot params; drop preseed) (item 10).
6. Generate page (xorriso with Arch tree) + emulator test (items 11–12).
7. PKGBUILD into a buildable AUR-style package; remove `debian/` at the end.

## Conventions

- Keep every original Copyright/GPL-3 header intact (license: GPL-3 for the
  whole derivative; see `LICENSE`).
- Keep dual-support code paths optional: CAIC should first recognize Arch
  ISOs, with Ubuntu/Debian support retained while the port matures.
- Grey out / hide Arch-irrelevant UI (preseed, snaps) until replaced, rather
  than deleting code, to ease upstream merges.
